# Contribuir

Gracias por ayudar a mejorar este paquete.

## Requisitos

- PHP 8.3 o 8.4
- Laravel 12 o 13
- Composer 2

## Flujo de trabajo

1. Instala dependencias con `composer install`.
2. Ejecuta pruebas con `composer test`.
3. Revisa formato con `composer lint`.
4. Revisa análisis estático con `composer analyse`.

## Estilo

- Código PHP con Laravel Pint.
- Documentación pública en español.
- Mantén la API pública estable: facade, servicio, configuración, rutas y estructura JSON.

## Reportar errores

Incluye:

- versión de PHP
- versión de Laravel
- versión del paquete
- expresión impresa o XML de ejemplo sin datos sensibles
- error completo o respuesta recibida
